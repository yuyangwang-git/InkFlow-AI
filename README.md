# ✨ 复制 AI 网页公式（Word/LaTeX）

一个面向日常学习与科研写作的 Tampermonkey 用户脚本。  
在支持的网站中，双击公式即可快速复制，支持在 **Word 公式（MathML）** 和 **LaTeX 源码** 之间切换。

## 🔗 安装链接

- Greasy Fork：  
👉 [点击这里安装脚本](https://greasyfork.org/zh-CN/scripts/566889-%E5%A4%8D%E5%88%B6ai%E7%BD%91%E9%A1%B5%E5%85%AC%E5%BC%8F-word-latex)

## 🚀 主要特性

- ✅ 双击公式即可复制，无需手动选中复杂节点
- ✅ 支持两种复制模式：
  - `Word 公式（MathML）`：便于粘贴到 Word 公式编辑器
  - `LaTeX 源码`：便于写论文、笔记和 Markdown
- ✅ 页面右下角提供模式切换按钮，随时切换
- ✅ 鼠标悬停公式时可显示 LaTeX 预览

## 🌐 支持网站

- `chatgpt.com`
- `gemini.google.com`
- `deepseek.com`
- `wikipedia.org`
- `zhihu.com`
- `stackexchange.com`

## 📦 安装方法

1. 安装浏览器扩展：`Tampermonkey`（或兼容的用户脚本管理器）
2. 打开上方 Greasy Fork 链接，点击“安装此脚本”
3. 安装完成后刷新目标网页即可生效

### 🛠️ 手动安装（可选）

1. 新建用户脚本
2. 将 `main.user.js` 的内容粘贴进去并保存
3. 刷新目标网页

## 🧭 使用方法

1. 打开含公式的页面
2. 右下角按钮切换复制模式：
   - 显示“`📋 Word 公式`”时，双击复制为 MathML
   - 显示“`📋 LaTeX 源码`”时，双击复制为 LaTeX
3. 双击目标公式完成复制
4. 在 Word、Markdown 编辑器或 LaTeX 编辑器中粘贴

## ℹ️ 说明

- 本脚本不上传你的内容，不依赖任何后端服务
- 复制结果受目标网站公式结构与目标编辑器兼容性影响
